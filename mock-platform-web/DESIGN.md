# 前端视觉规范

## 设计基础

视觉参考为 2026-09-15 实际访问的 Linear、Attio、Vercel 官网与公开产品展示：浅色工作区、紧凑导航、中性色主操作、细分隔线和明确的文字层级。不使用品牌资源、远程字体或额外依赖。

- `src/styles/tokens.css`：颜色、字体、4px 间距基础、4/6/8px 圆角、轻阴影及尺寸变量。
- `src/styles/element-plus.css`：Element Plus 控件、表格、弹窗、抽屉、状态和反馈样式。覆盖规则需要兼容按需加载的组件 CSS。
- `src/styles/main.css`：工作区、筛选网格、分页、详情和响应式布局。
- 字体使用系统字体栈；主标题 20px，内容 12–13px，表头和辅助文字 11–12px。标识符和 JSON 使用等宽字体。
- 主操作使用石墨色；成功、警告、危险沿用原有语义，使用低饱和颜色；状态不可只依赖颜色传递。

## 公共组件

- `PageHeader`：标题插槽、说明和操作插槽。页面继续持有按钮事件、loading、disabled 和权限条件。
- `AppIcon`：本地 SVG 线性图标；装饰图标不进入无障碍名称，图标按钮和折叠导航保留文本标签。
- `EmptyState`：复用 Element Plus Empty，更换为小型线性图标，保留各页原有空态描述。
- `JsonEditor`、`HttpErrorAlert`：继续使用原组件的解析、格式化和错误清除行为，通过公共 CSS 统一外观。

## 页面约定

- 数据管理使用表格。主表通过 Element Plus `max-height` 保留表头及内部滚动，列宽、固定操作列和分页事件沿用现有实现。
- 普通表格行高约 44px，允许明确的主次两行内容；长标识符和时间列使用溢出提示。
- 单行筛选自动换行；请求和审计使用网格筛选。日期范围控件必须允许缩小，不得撑开网格。
- 对话框限制在窗口范围内，长内容在正文滚动，底部操作保持可见；抽屉统一标题边界和正文间距。
- 小窗口保留表格横向滚动，不转换成卡片。窄屏导航使用图标，提供可访问名称。

## 验证

运行 `npm test`、`npm run type-check`、`npm run lint`、`npm run build`。

视觉检查覆盖全部 14 个业务页面、404、错误/加载/空态、长表格、分页、筛选、确认框、JSON 表单和详情抽屉；检查 1280px 工作区及 768/600/390px 窄窗口。真实后端不可用时，可使用独立的本地只读 fixture 服务，通过既有 `VITE_CONTROL_TARGET` / `VITE_RUNTIME_TARGET` 环境变量启动独立预览。fixture 数据不进入应用代码，也不能代替真实后端写操作验收。
